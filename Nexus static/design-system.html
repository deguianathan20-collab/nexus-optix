Nexus Brand Group Design System

Tokens, components, and layout primitives for building new pages. Everything here ships in one stylesheet — design-system.css. Prefix nx- guarantees no collision with existing per-page CSS.

Using the design system

Add one stylesheet link to a new page's <head>, then add the nx class to <body> for the base typography reset. Component classes are opt-in — sprinkle them anywhere you want the design-system look.

<link rel="stylesheet" href="/design-system.css">

<body class="nx">
  <section class="nx-section">
    <div class="nx-container">
      <h1 class="nx-h1">Build <span class="nx-accent">something</span> new</h1>
      <p class="nx-body-lg">Page copy goes here.</p>
      <a href="/contact" class="nx-btn nx-btn--primary">Get Started</a>
    </div>
  </section>
</body>

Typography

Montserrat sets the whole site. Headings are 800-weight with negative letter-spacing for a tight, confident look. Body copy is 1.7 line-height for legibility on long-form pages.

.nx-h1 / 56px / 800

Build trust through performance

.nx-h2 / 44px / 800

A full-service agency

.nx-h3 / 32px / 700

Specialized in marketplaces

.nx-h4 / 24px / 700

Section heading

.nx-eyebrow / 12px / 800Eyebrow label
.nx-body-lg / 18px

Larger body copy for hero subtitles and emphasis.

.nx-body / 16px

Default body copy — used for paragraphs across the site.

.nx-body-sm / 14px

Small body copy for captions, helper text, and footnotes.

Gradient accent — wrap any word/phrase in .nx-accent

Buttons

Cards

Default card for content blocks. Add nx-card--hover for clickable cards (lifts on hover + gradient bottom-border reveal). Add nx-card--accent-top for emphasis.

Default card

Background, padding, subtle shadow, light border. The neutral container for any boxed content.

Hoverable card

Lifts and reveals a gradient bar on hover. Use for clickable navigation or feature grids.

Accent-top card

A 4px gradient bar sits along the top edge. Use for "featured" callouts.

<div class="nx-card">...</div>
<div class="nx-card nx-card--hover">...</div>
<div class="nx-card nx-card--accent-top">...</div>

Forms

Inputs are 1.5px border, blue focus ring. Labels are uppercase and 800-weight to read as system labels, not body copy. Use .nx-form-row for side-by-side fields.

We'll respond within one business day.
<div class="nx-form-group">
  <label class="nx-label" for="email">Work Email</label>
  <input id="email" class="nx-input" type="email">
</div>

Badges

Small label pills for categorization. The "brand" variant uses a soft tint of the green-blue palette; use it for category tags. Use --new sparingly to flag genuinely new content.

FEATURED ADVERTISING CATALOG STRATEGY NEW 
<span class="nx-badge nx-badge--brand">FEATURED</span>

Layout

All sections wrap their content in .nx-container (max-width 1200px, centered, 24px gutter). For long-form text use .nx-container--narrow (max-width 800px). Sections come in light, soft, dark, and gradient flavors.
